# 镜头 20：并发模型落地

## 检查点

- 单写者：每个可变状态的写线程数
- 按 key 分片：同 key 是否固定 owner
- 队列有界 + 满行为显式
- 锁内四不做（I/O/回调/分配/取二锁）
- 固定锁顺序
- 读多写少是否快照
- 并发可观测（线程名/队列深度/延迟）
- Reactor 三坑：回调阻塞、跨线程写 fd、回调内销毁自身

## 信号（先扫后读）

- lock 调用
- mutex|queue|select|epoll|async|detach

## 级别上限

违反 CONC-1..5 最低 P1，致故障 P0；CONC-6/7 P2

## 取证要求

写点清单/锁区间/交错序列；无 TSan 等证据时置信度 ≤medium，不得单独作 P0

> 本镜头只对**信号命中的位置**深读。没有信号就不报——这是控制噪声的唯一办法。
