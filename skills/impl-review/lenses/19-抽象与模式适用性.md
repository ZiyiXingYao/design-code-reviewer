# 镜头 19：抽象与模式适用性

## 检查点

- 同一维度类型分支在 ≥3 处重复且分支集相同
- 同一逻辑在 ≥3 处、每处 ≥15 行
- 同概念 ≥2 个类型/函数名
- bool 参数 ≥3 或参数 ≥7
- 反向：接口实现数=1、基类子类数=1、策略分支=1

- 资源获取/释放散落在 ≥3 处（缺 RAII 或统一封装）

## 信号（先扫后读）

- switch 语句
- 类型相关 if 链
- 实现数=1 的接口定义

## 级别上限

**所有模式类发现封顶 P2**；概念漂移已导致重复缺陷可 P1

## 取证要求

diff 的完整前后行 + 重复处清单

模式层面的完整参照见 `../patterns.md`（GoF 23 反查/正查表）；本镜头只报信号成立的位置。

> 本镜头只对**信号命中的位置**深读。没有信号就不报——这是控制噪声的唯一办法。
