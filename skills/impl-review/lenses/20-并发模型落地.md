# 镜头 20：并发模型落地

## 检查点

- 单写者：每个可变状态的写线程数
- 按 key 分片：同 key 是否固定 owner
- 队列有界 + 满行为显式
- 锁内四不做（I/O/回调/分配/取二锁）
- 固定锁顺序
- 读多写少是否快照
- 并发可观测（线程名/队列深度/延迟）
- Reactor 三坑：回调阻塞、跨线程写 fd、回调内销毁自身

## 信号（先扫后读）

- lock 调用
- mutex|queue|select|epoll|async|detach

## 级别上限

违反 CONC-1..5 最低 P1，致故障 P0；CONC-6/7 P2

## 取证要求

写点清单/锁区间/交错序列；无 TSan 等证据时置信度 ≤medium，不得单独作 P0

> 本镜头只对**信号命中的位置**深读。没有信号就不报——这是控制噪声的唯一办法。

## 第四组：定时扫描专项

| 检查点 | 信号 | 级别 |
|---|---|---|
| 扫描散落 | 多处"循环内 sleep"轮询、各模块自建定时线程 | P1 |
| 扫描可重入 | 上轮未完下轮已起（无 in-flight 标记） | P1 |
| 周期 ≥ 超时阈值 | 周期值与超时值逐对比较 | P1 |
| sleep 累加代替 deadline | 长时间运行后漂移累积 | P2 |
| 模型混用 | 同模块内回调 + 阻塞睡眠 + 独立起线程并存 | P1 |
